How to Install All Libraries

Install the required libraries via Arduino IDE → Tools → Manage Libraries → search & install each: Adafruit ST7735 and Adafruit GFX. That is all! The joysticks and IR obstacle sensor use only built-in Arduino commands (analogRead() / digitalRead()), so they need no library.

How to Upload Game Code
  1. Open Arduino IDE
  2. Copy the game code from this website
  3. Paste the code into Arduino IDE (Ctrl+V)
  4. Select Board: Tools → Board → Arduino Uno
  5. Select Port: Tools → Port → COM port
  6. Click the Upload button (→ arrow)
  7. Wait for "Done uploading"

Wiring Diagram

1. ST7735 TFT DISPLAY

TFT VCC      -> Arduino 5V
TFT GND      -> Arduino GND
TFT CS       -> Arduino Pin 10
TFT RST      -> Arduino Pin A1
TFT A0/DC    -> Arduino Pin A0
TFT SDA/MOSI -> Arduino Pin 11
TFT SCK      -> Arduino Pin 13
TFT LED/BL   -> Arduino 3.3V

2. JOYSTICK 1 (Player 1)

Joystick 1 VCC -> Arduino 5V
Joystick 1 GND -> Arduino GND
Joystick 1 VRx -> Arduino Pin A2
Joystick 1 VRy -> Arduino Pin A3
Joystick 1 SW  -> Arduino Pin 2

3. JOYSTICK 2 (Player 2)

Joystick 2 VCC -> Arduino 5V
Joystick 2 GND -> Arduino GND
Joystick 2 VRx -> Arduino Pin A4
Joystick 2 VRy -> Arduino Pin A5
Joystick 2 SW  -> Arduino Pin 3

4. IR OBSTACLE SENSOR

IR VCC -> Arduino 5V
IR GND -> Arduino GND
IR OUT -> Arduino Pin 4

The Arduino Uno has one 5V pin — share it between the TFT, both joysticks and the IR sensor using a breadboard or joined wires. The TFT backlight uses the 3.3V pin.
